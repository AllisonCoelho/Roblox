# AuraAssets — templates importados no Roblox Studio

O Rojo coloca esta pasta em `ReplicatedStorage.AuraAssets`. Cada aura do pipeline v2 tem aqui um
`<Nome>.rbxm` salvo no Studio (Model com os MeshParts publicados). Os módulos do cliente clonam
esses templates; nenhum `MeshId` é atribuído em runtime.

| Arquivo | Status |
|---|---|
| `Senbonzakura.rbxm` | **ainda não existe** — aguardando a importação manual (ver `assets/auras/senbonzakura/README.md`) |

Enquanto o `.rbxm` não existir, a pasta vai vazia para o jogo e a Senbonzakura não é montada
(aviso no Output). Este README não vira instância no jogo.
